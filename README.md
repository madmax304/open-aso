# open-aso

> **The open-source alternative to AppTweak and Sensor Tower.**

Agent-first App Store Optimization for indie iOS developers. open-aso gives your AI agent (Claude, Cursor, or any MCP client) real App Store data and ASO expertise. You pay only DataForSEO's cost price, with no subscription.

🚧 **Under construction.** v0.1 is in progress. See [SCOPE.md](SCOPE.md) for what's coming.

- Keyword research, with volume and difficulty
- Rank tracking
- Competitor tracking and keyword gaps
- Reviews
- Metadata writing that checks itself against Apple's rules
